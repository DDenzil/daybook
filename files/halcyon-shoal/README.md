# Halcyon Shoal — offshore gas field, interactive 3D

A fictional, representative offshore gas complex built at true scale (1 unit = 1 metre): central processing platform (HS-CPP), living quarters with helideck (HS-LQ), bridge, five unmanned wellhead platforms 4–6 km out, subsea flowlines and an export trunkline, a supply vessel, a crew-change helicopter, marine life and a shore receiving terminal about 78 km away.

All production figures are **simulated**. The facility, vessel and names are fictional.

## Run it

The site is static files. It needs to be served over HTTP (ES modules do not load from `file://`).

- **GitHub Pages:** push this folder to a repository and enable Pages (Settings → Pages → Source: GitHub Actions). The included workflow `.github/workflows/pages.yml` publishes the folder as it is; there is no build step.
- **Locally:** `python3 -m http.server 8000` in this folder, then open <http://localhost:8000>.

Supported browsers: Safari on iPhone, Samsung Internet and Chrome on Samsung phones, Edge and Chrome on PCs. WebGL 2 is required.

## Controls

| Action | Mouse | Touch |
| --- | --- | --- |
| Orbit | Left-drag | One finger |
| Pan | Right-drag | Two fingers |
| Zoom | Scroll | Pinch |
| Hide or show controls | `H` | ◱ button |

The **Views** bar flies the camera to the process platform, flare, living quarters, subsea, a wellhead or the shore terminal; **Tour** plays them in sequence. The **field map** shows the whole field at true scale: drag a wellhead to move it (its flowline is re-routed along the seabed), or press **+ Add** and tap the map to place a new one. The **Events** tab starts a helicopter crew change, a supply-vessel voyage with a crane lift, or a whale shark / Bryde's whale sighting, and lets the camera follow them. **Settings** (⚙) changes quality tier, time of day, sea state, simulation speed, labels and volume.

## Quality tiers

The tier is chosen automatically and steps down if the frame rate drops. It can be fixed in Settings.

| | Phone | PC (integrated graphics) | Plus (dedicated graphics) |
| --- | --- | --- | --- |
| Target | 30 fps | 60 fps | 60 fps |
| Render resolution | 70% | 90% | 100% |
| Ocean waves | 6 | 8 | 10 |
| Shadow map | 1024 | 2048 | 4096 |
| Bloom, heat haze | off | on | on |
| Anti-aliasing | FXAA | SMAA | SMAA |
| Schooling fish | 150 | 600 | 1,500 |

Reference devices: iPhone 11 Pro, Samsung Galaxy S23, Intel Core i7 PC with integrated graphics, Alienware 13 R3.

## Editing settings

`data/settings.json` controls the starting wellhead positions (`[x, z]` in metres, CPP at `[0, 0]`, `-z` is north), flow rates and pressures, telemetry constants, logistics timings and the default time of day, sea state and volume. Reload the page after editing.

## Models

Every model is generated by the Python scripts in `tools/blender/` (Blender 4.2 or newer; built and tested with Blender 5.3). They bake ambient occlusion with Cycles and export `.glb` files. The scripts draw textures with Pillow, which Blender does not bundle: install it once into Blender's own Python (`<blender>/<version>/python/bin/python -m pip install pillow`), or run the scripts with the `bpy` package from pip (`pip install bpy pillow`).

```
blender -b -P tools/blender/build_all.py              # all models
blender -b -P tools/blender/build_all.py cpp psv      # selected models
node tools/pack_models.mjs                            # compress *.raw.glb -> *.glb (needs Node and npx)
```

To replace a model with an artist-made one, export a `.glb` with the same file name into `models/`, keeping the node names listed in `models/README.md` (the app animates and positions those nodes). No code changes are needed.

## Sound

The sound engine is complete; the sound files are supplied separately. Put each file in `audio/` named by its ID (for example `audio/amb_sea_calm.mp3`) and add the ID to `audio/manifest.json`. Unlisted files are skipped. See `audio/README.md` for the list and the delivery specification. Sound starts muted; the 🔇 button turns it on.

## Notes

- The site is public on GitHub Pages. Keep company data, photographs, documents and staff names out of the repository.
- Transits from shore are time-skipped: the vessel appears about 2 km out and the helicopter about 6 km out; the HUD says so.
- `window.HS` exposes the running scene in the browser console for debugging.
