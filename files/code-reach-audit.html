How the scan works

The page reads each file as text and matches it against rules covering network calls, loaded resources, storage and device access, code execution, secrets, transport security, file system and OS access, cross-window messaging and obfuscation. It never runs the code.

Addresses built from variables are resolved when the variable is assigned a plain string in the same file; otherwise they show as {name}. Minified, obfuscated or runtime-generated code can hide calls, so use this as a first-pass review alongside a code review, not as a penetration test. Secrets are masked on screen and in every export. Matches inside comments are kept but rated Info.
